## Dependency Tree (Critical Path)

1. **App Startup** (`lib/main.dart`):
   - Initializes `window_manager` for custom title bar
   - Calls `SupabaseService.initialize()` to set up auth + cloud sync

2. **State Initialization** (`lib/providers/app_state.dart`):
   - `DatabaseService.initialize()` - Sets up SQLite with FFI
   - `EntryScannerService` - Monitors entry directories
   - `SyncService` - Bidirectional sync to Supabase

3. **Data Layer**:
   - **SQLite**: papers, tags, paper_tags, papers_fts (local-first)
   - **Supabase PostgreSQL**: user_papers, user_tags, user_paper_tags, shared_catalog (cloud)
   - **Sync mechanism**: `SyncService` pushes dirty records (sync_key, dirty flag, remote_id)

4. **Services**:
   - `PdfService` - Uses Isolate.run() to extract text/title via Syncfusion
   - `ArxivService` - HTTP queries to `http://export.arxiv.org/api/query`
   - `BibtexService` - Searches DBLP and ACM for paper metadata
   - `LlmChatService` - Calls Supabase Edge Function `chat-with-paper`
   - `RecommendationService` - Calls Supabase RPC functions
